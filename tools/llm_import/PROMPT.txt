Convert the attached university major-map PDF into plain text following
the format specification and worked examples below, exactly. Output only
the converted text - no commentary, no markdown, no code fences.

=== WHAT THE PDF LOOKS LIKE ===

Page 1 (sometimes pages 1-2) is a table of eight semesters. Each
semester starts with a dark header row like "Semester One (15 Credit
Hours)". Each row below it is one requirement, with columns:

  [!] | Course Subject and Title | Credit Hours | Min. Grade | Program GPA | Code | Prerequisites | Notes

The last page has a "Graduation Requirements Summary" table (Minimum
Total Hours, Minimum Major Requirements Hours, College & Program
Requirements Hours, Carolina Core Hours, Minimum Institutional GPA) and
a numbered list of program notes.

Notice, from each row above:
- Row 1: the "!" first column becomes "!" after the Req number. The
  course title and the Prerequisites column are NOT copied.
- A footnote on a course row goes on the Req line: a row "WGST 112
  Introduction to Women's Studies^5" becomes "Req: 1 ! ^5". Footnotes on
  placeholder rows stay on their Slot line.
- Row 2: "or" between two courses = two Course lines in ONE block. No
  Credits line - course credits are looked up automatically.
- Row 3: "(fall only)" becomes "Offered: fall". Also "(spring only)" ->
  "Offered: spring", "(offered fall & summer only)" -> "Offered: fall
  summer".
- Row 4: one "or" option is a course, the other is not. The non-course
  option becomes a Slot line, and the block keeps the printed credits.
- Row 5: neither option is a course code, so both are Slot lines.
  Footnote superscripts stay as ^4 and ^7 on their own option.
- Row 6: "(300-level or above)" becomes "Level: 300+". A range like
  "(300-500 level)" becomes "Level: 300-500". Other parenthetical
  conditions you cannot classify go on a "Qual:" line, copied verbatim.

Notice:
- EVERY numbered note becomes a Note block. Text: is always last and
  holds the note's complete wording, exactly as printed, on one line.
- A note that specifies acceptable courses ALSO gets structured lines
  before Text. Note 6 grants a whole range, so it gets "From: CSCE
  500+" - NEVER expand a range into a list of course numbers.
- Note 7: "GEOG 285, 349, 535, 541" expands to one Course line each,
  repeating the subject. A restricted course (GEOG 595) stays listed
  with its restriction in parentheses. A constraint on the whole group
  becomes a Rule line.

=== RULES ===

1. Every table row on every page becomes exactly one Req block. Include
   repeated rows (five "Elective^7" rows = five blocks). Req numbering
   restarts at 1 in each semester. Blank line between all blocks.
2. Semester headers: use the name as printed ("One" ... "Eight", or
   "Fall" / "Spring" / "Summer" on accelerated plans - summer terms are
   semesters too). Credits: the number or range printed in the header.
3. Course lines hold ONLY a subject-and-number code like "ENGL 101" or
   "MATH 344L". No titles, no credits, no footnotes on Course lines - a
   course row's footnote digits go on its Req line as ^n.
4. Slot lines hold the row's wording for anything that is not a course
   code, with footnote digits as ^n. Every block that contains a Slot
   line must keep the row's printed credits as a Credits line.
5. Allowed keys, and no others: Semester, Credits, Req, Course, Slot,
   Grade, Code, Level, Offered, Qual, Summary, Total, Major, College,
   Core, GPA, Note, Hours, From, Rule, Text.
6. Code holds only requirement codes as printed (CC-CMW, CC-ARP, CC-SCI,
   CC-GFL, CC-GHS, CC-GSS, CC-AIU, CC-CMS, CC-INF, CC-VSR, CC-INT, PR,
   MR, CR, and slash or space combinations like CC/PR) - never ordinary
   words.
7. Ignore completely: the Prerequisites column, the Program GPA column
   (the "*" marks), the code legend, progression standards, disclaimers,
   advising paragraphs, and residency requirements.
8. Copy only what the PDF states. Never invent a course code for a row
   that does not print one - "Social Science" is a Slot, not a course
   you choose for it. Never add rules, credits, or grades that are not
   printed. If you cannot read part of the PDF, write the block as a
   Slot with "Qual: unreadable" rather than guessing.
